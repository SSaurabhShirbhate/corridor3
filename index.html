The Gallery: Selected Works and Case Studies

In the 3D gallery room, you can walk through an exhibition of my most significant commercial and personal projects. Here is a detailed breakdown of the work created by Saurabh Shirbhate.

FCBankers - GhostDraft Configurator

FCBankers is a Sapiens GhostDraft configuration project built in Core Java with MySQL persistence. Insurance products are authored as structured XML/XSD/JSON documents and validated before they ever reach a build, letting markets configure their own products without hand-written code per release. Rollout time dropped from weeks to days, and configuration defects are caught at authoring time, not runtime.

StarrKInsurance - Policy Technical Analysis

StarrKInsurance is a policy technical analyst engagement on the Sapiens GhostDraft configurator. The work automated document generation and workflow management across the policy lifecycle and established a defined troubleshooting path for configuration defects, so policy documents generate automatically and defect resolution is tracked instead of ad hoc.

PolicyPal AI - LLM + RAG Assistant

PolicyPal AI is a retrieval-augmented assistant for policy documents. Built with Java and Spring Boot over embedded policy PDFs, it lets an LLM answer questions grounded in the actual documents, with strict citations so every answer points at its source page. Answering a policy question went from minutes of searching to seconds.

LedgerLens - Microservices Expense Tracker

LedgerLens is a microservices expense tracker with AI insights. The monolith was split into ledger, categorisation, and insights services built with Spring Boot, MySQL, and Dockerised deployments. An AI service auto-categorises transactions and surfaces spending patterns — the ledger writes itself, and so does the analysis.
